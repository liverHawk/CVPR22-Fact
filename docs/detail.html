Forward Compatible Training (FACT)

Few-Shot Class-Incremental Learning (FSCIL) に対する画期的なアプローチ。従来の「過去モデルの忘却を防ぐ事後的一致（Retrospective）」から脱却し、 ベースセッションにおいて仮想プロトタイプ（Virtual Prototypes）の事前直交配置と中間層Mixupによる仮想インスタンス予測を行うことで、 将来の未知クラスのために余白を予約する前方向互換学習（Forward Compatible Training）を実現します。

Target Task
FSCIL (N-way K-shot)
Key Backbone
ResNet-18 / ResNet-20
Core Strategy
Orthogonal Pre-allocation
Datasets Supported
CIFAR100, CUB200, MiniImg

全体アーキテクチャ & コンセプト

なぜ FACT なのか？ (Prospective vs Retrospective)
従来手法は、新セッションが来るたびに過去の重みに近づける正則化を行いますが、新クラスがわずか5枚（5-shot）しかないため過学習と忘却が発生します。 FACT は最初のベースセッション（Session 0）で未知クラス領域をあらかじめ直交ベクトルで確保し、特徴量をその余白を避けるように圧縮することで、新セッションでの衝突をゼロコストで回避します。

1. train.py — エントリポイント & 引数管理

コマンドライン引数の解析、乱数シードの設定、GPU環境の初期化を行い、指定されたプロジェクト（-project fact または -project base）のトレーナーを動的にインポートして学習を実行します。

引数名 (Argument) デフォルト値 選択肢 / 型 機能・解説
-project 'base' 'base', 'fact' 実行する手法プロジェクト。FACT提案手法を実行する場合は -project fact を指定。
-dataset 'cub200' 'cifar100', 'cub200', 'mini_imagenet' 対象データセット。各データセットの分割設定は dataloader/data_utils.py に定義。
-epochs_base 100 int Session 0（ベースクラス）の事前学習エポック数（例: CIFARは600, CUBは400, Miniは1000）。
-lr_base / -lr_new 0.1 float ベース学習および新規インクリメンタルセッションにおける初期学習率。
-schedule 'Step' 'Step', 'Milestone', 'Cosine' 学習率スケジューラ。コサインアニーリングまたはステップ減衰を選択可能。
-temperature 16 float コサイン類似度分類器で特徴量と重みの正規化後にスケーリングする温度係数 $\tau$。
-balance 1.0 float FACT特有の損失バランス係数。補助損失（仮想プロトタイプ損失・Mixup損失）の重みを調整。
-loss_iter 200 int FACTの複合損失を適用し始めるエポック数（初期学習が安定するまでのWarm-up期間）。
-alpha 2.0 float 仮想インスタンス生成（中間Mixup）の Beta 分布パラメータ $\beta \sim \text{Beta}(\alpha, \alpha)$。
-eta 0.1 float 推論時（test_intergrate）における仮想プロトタイプ射影スコアの統合比率。
BASH — 実行スクリプト例 
# CIFAR-100 での FACT 学習
python train.py -project fact -dataset cifar100 \
    -base_mode "ft_cos" -new_mode "avg_cos" \
    -gamma 0.1 -lr_base 0.1 -epochs_base 600 -schedule Cosine \
    -temperature 16 -batch_size_base 256 \
    -balance 0.001 -loss_iter 0 -alpha 0.5

2. utils.py — 共通ユーティリティ

Reproducibility

set_seed(seed)

random, numpy, torch (CPU & CUDA) の乱数シードを一括で固定。 seed != 0 の場合、cuDNN の決定論的実行（deterministic=True, benchmark=False）を強制して完全な再現性を保証します。

Hardware

set_gpu(args)

args.gpu に渡された GPU ID 文字列（例: '0,1,2,3'）を環境変数 CUDA_VISIBLE_DEVICES に設定し、利用可能な GPU 数を返却します。

Tracking

Averager & Timer

Averager: 損失や精度のオンライン平均を保持。
Timer: 経過時間を計測し、秒 (s)、分 (m)、時間 (h) に適応的にフォーマット表示。

Metrics

count_acc & count_acc_topk

モデルの出力ロジット（Logits）と正解ラベルから Top-1 および Top-$k$ 精度を計算。GPU メモリ上にテンソルを維持したまま高速に評価可能です。

Evaluation

count_acc_taskIL

Task-Incremental Learning の評価用。各サンプルがどのセッションに属しているかが既知という前提で、他セッションのロジットに $-10^9$ のマスクを適用して精度を算出します。

Visualization

confmatrix

混同行列（Confusion Matrix）を正規化計算し、matplotlib を使用してヒートマップ形式の PDF ファイル（カラーバー有無の2種）を保存します。

4.2. FACT 提案手法の核となるメカニズム

models/fact/Network.py
① 仮想プロトタイプの直交事前割り当て (Orthogonal Pre-allocation)

ベースクラス学習の段階で、全クラス数（pre_allocate = args.num_classes）分の分類器重みを直交初期化（nn.init.orthogonal_）します。 未知クラスに対応する重みは dummy_orthogonal_classifier として勾配更新を停止し、将来のクラスのために空間を「予約」しておきます。 

# models/fact/Network.py より抜粋
self.pre_allocate = self.args.num_classes
self.fc = nn.Linear(self.num_features, self.pre_allocate, bias=False)
nn.init.orthogonal_(self.fc.weight)

# 未知クラス領域をダミークラス分類器として固定
self.dummy_orthogonal_classifier = nn.Linear(self.num_features, self.pre_allocate - self.args.base_class, bias=False)
self.dummy_orthogonal_classifier.weight.requires_grad = False
self.dummy_orthogonal_classifier.weight.data = self.fc.weight.data[self.args.base_class:, :]
models/fact/helper.py
② 複合損失によるベース学習 (Mixup & Virtual Instance)

base_train() では、通常のクロスエントロピー損失に加えて、中間特徴量同士を合成する Mixup によって未知クラスの疑似サンプルを生成し、 あらかじめ確保した仮想プロトタイプへとマッピングする4段階の複合損失を適用します。

L_total = L_base + balance * (L2 + L3 + L4)
  • $L_{\text{base}}$: ベースクラスに対する通常の分類 Cross-Entropy 損失
  • $L_2$: 既知クラス埋め込みを圧縮し、ダミークラス領域とのマージンを空ける損失
  • $L_3$: 中間層 Mixup で生成した疑似サンプルを仮想プロトタイプ（新クラス予約席）に割り当てる損失
  • $L_4$: 疑似サンプルが既知クラス領域に侵入しないように強制分離する損失
models/fact/fscil_trainer.py
③ フォワードコンパチビリティ統合推論 (test_intergrate)

新クラスセッションの評価時、新旧プロトタイプの直接分類スコア（$logits_2$）だけでなく、 事前に配置していたダミー直交分類器との射影行列（$proj\_matrix$）を介した推論スコア（$logits_1$）をパラメータ $\eta$ でアンサンブルします。 

# models/fact/fscil_trainer.py より抜粋
proj_matrix = torch.mm(self.dummy_classifiers, F.normalize(torch.transpose((model.module if hasattr(model, "module") else model).fc.weight[:test_class, :], 1, 0), p=2, dim=-1))

# 仮想プロトタイプ射影と直接FC出力の加重統合
logits = eta * F.softmax(logits1, dim=1) + (1 - eta) * F.softmax(logits2, dim=1)

5. セッション進行と実行パイプライン

  1. 初期化フェーズ: train.py が起動 $\to$ 乱数固定 $\to$ set_up_datasets で各データセットの分割パラメータ設定 $\to$ MYNET を全クラス分直交初期化。
  2. Session 0 (ベースセッション学習): ベースクラスデータで epochs_base 回学習。 loss_iter 以降は中間Mixupと仮想プロトタイプ損失を合成した複合損失を適用。 完了後、replace_base_fc により各クラスサンプルの平均埋め込みベクトルで重みを更新。
  3. Session 1〜N (インクリメンタルセッション): バックボーンを固定（eval()）し、新しい Few-shot クラスの平均埋め込みをプロトタイプとして FC 層に登録（update_fc_avg）。
  4. 評価フェーズ: test_intergrate により、現在までに遭遇した全クラスのテスト画像に対し、射影アンサンブルスコアで Top-1 精度を算出。
