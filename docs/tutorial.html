FACT 拡張チュートリアル

FACT コードベースに自作のデータセットや新しい特徴抽出器（ResNet-50, ViT, ConvNeXt 等）を組み込むための開発者向けガイドです。 FACT 固有の「中間層 Mixup（pre_encode / post_encode）」や「直交プロトタイプ事前配置」の制約を満たしながら安全に拡張する手順を解説します。

1. コンポーネント間の依存関係

新しいデータセットやバックボーンを組み込む場合、変更が必要なファイルと相互の依存関係は下図の通りです。

2. 新しいデータセットの追加手順

1

セッションインデックスファイルの作成

data/index_list/<new_dataset>/ ディレクトリを作成し、各セッションで使用するサンプルインデックス（テキスト）を作成します。

  • session_1.txt: ベースセッション用（全ベースクラスの画像パスまたはID）
  • session_2.txt 〜 session_N.txt: 新規セッション用（$N$-way $\times$ $K$-shot 分の少数画像）
CUB-200 形式の例
1行につき 画像の相対パス クラスID（例: 001.Black_footed_Albatross/image_0001.jpg 0）を記述するのが標準的です。
2

Dataset クラスの実装 (dataloader/<dataset>/<dataset>.py)

torch.utils.data.Dataset を継承したクラスを作成します。base_sess=True の場合はベースクラスのみ、index_path が指定された場合はテキストファイル内のFew-shotサンプルのみをフィルタリングします。

dataloader/my_dataset/my_dataset.py (テンプレート) 
class MyDataset(Dataset):
    def __init__(self, root='data/', train=True, transform=None,
                 index_path=None, index=None, base_sess=False):
        self.root = os.path.expanduser(root)
        self.train = train
        # 前処理パイプライン
        self.transform = transform or transforms.Compose([
            transforms.Resize(256),
            transforms.RandomResizedCrop(224) if train else transforms.CenterCrop(224),
            transforms.RandomHorizontalFlip() if train else transforms.Lambda(lambda x: x),
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
        ])
        self._load_data()
        if base_sess:
            self.data, self.targets = self._select_classes(self.data, self.targets, index)
        elif index_path is not None:
            self.data, self.targets = self._select_from_txt(index_path)
        elif index is not None:
            self.data, self.targets = self._select_classes(self.data, self.targets, index)

    def __len__(self): return len(self.data)
    def __getitem__(self, idx):
        img = Image.open(self.data[idx]).convert('RGB')
        return self.transform(img), self.targets[idx]

3. 新しいバックボーンの追加手順

FACT バックボーンの必須制約: 2段階エンコード (pre_encode / post_encode)
FACT では、未知クラスの疑似インスタンスを生成するために中間特徴マップレベルでの Mixup を実行します。 そのため、バックボーンは必ず「入力 $\to$ 中間層」と「中間層 $\to$ 最終特徴量」に分割して呼び出せる構造にする必要があります。
1

バックボーンクラスの作成 (models/<backbone>.py)

例: ResNet-50 を中間分割可能な構造でラップします。

import torch.nn as nn
from torchvision.models import resnet50

class ResNet50Backbone(nn.Module):
    def __init__(self, pretrained=False):
        super().__init__()
        m = resnet50(pretrained=pretrained)
        # 浅い層 (pre_encode で実行)
        self.conv1 = m.conv1; self.bn1 = m.bn1; self.relu = m.relu
        self.maxpool = m.maxpool; self.layer1 = m.layer1; self.layer2 = m.layer2
        # 深い層 (post_encode で実行)
        self.layer3 = m.layer3; self.layer4 = m.layer4
        self.out_features = 2048  # 出力次元
2

models/fact/Network.py への統合

MYNET にバックボーンのインスタンス化、pre_encode、post_encode を追加します。

# models/fact/Network.py
def pre_encode(self, x):
    if getattr(self.args, 'backbone', '') == 'resnet50':
        x = self.encoder.relu(self.encoder.bn1(self.encoder.conv1(x)))
        x = self.encoder.maxpool(x)
        x = self.encoder.layer1(x)
        x = self.encoder.layer2(x)
        return x  # 中間特徴マップを返す

def post_encode(self, x):
    if getattr(self.args, 'backbone', '') == 'resnet50':
        x = self.encoder.layer3(x)
        x = self.encoder.layer4(x)
        x = F.adaptive_avg_pool2d(x, 1).squeeze(-1).squeeze(-1)
        if 'cos' in self.mode:
            return self.args.temperature * F.linear(F.normalize(x, p=2, dim=-1), F.normalize(self.fc.weight, p=2, dim=-1))
        return self.args.temperature * self.fc(x)

4. トラブルシューティング

エラー内容 発生原因 対策
RuntimeError: shape mismatch in linear self.num_features とバックボーンの最終出力次元が不一致 self.num_features = self.encoder.out_features と正しく指定しているか確認。
RuntimeError: Given groups=1, weight of size... pre_encode の出力チャネル数が post_encode の第1層の期待チャネル数と不一致 Mixup の分割位置（例: layer2 の直後）が layer3 の入力チャネル数と完全に一致しているか確認。
Session 1 以降の精度が上がらない Few-shot のプロトタイプ計算時に正規化が漏れている avg_cos 分類器使用時は F.normalize の適用と温度係数 $\tau$ の調整（16〜24）を確認。
